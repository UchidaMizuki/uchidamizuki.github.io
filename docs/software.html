Software

R パッケージを開発しています。ソースは GitHub、多くは CRAN と r-universe から利用できます。

産業連関分析

  • econio — 産業連関分析
  • econiodatajp — すぐ使える日本の産業連関表データ
  • econioread — 産業連関表の読み込み
  • econagent — 経済学における効用関数・複合財
  • ndgras — nD-GRAS 法（RAS 法の多次元拡張）

政府統計・地理データ

  • jpstat — e-Stat API から政府統計を取得
  • jpcity — 市区町村コードの読み取りと変換
  • jpgrid — 地域メッシュコード（JIS X 0410）の操作
  • jpmap — 沖縄・小笠原を配置した日本地図

データ構造・ツール

  • dibble — 次元付きデータフレーム
  • timbr — 木・森構造のデータフレーム
  • stickyr — 属性が保持されるデータフレーム
  • adverbial — 部分適用・合成の関数ツール
  • navigatr — パイプ処理向けのナビゲーションメニュー
  • tarchives — targets パイプラインのパッケージ化
